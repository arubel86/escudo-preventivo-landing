# Regla de Email Marketing — Variable Obligatoria {$unsubscribe}

- **Mandato:** Todo correo electrónico en formato HTML creado para MailerLite debe incluir obligatoriamente el tag de desuscripción:
  `<a href="{$unsubscribe}">Cancelar suscripción</a>`
- **Motivo:** MailerLite bloquea el guardado y envío si no detecta esta etiqueta en el HTML del correo.
